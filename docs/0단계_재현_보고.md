# 0단계 재현 확인 보고 (2026-11-09)

**질문**: 조은정 교수 도구(section-verb-hedge-baseline)로 ACS 2020–2021 80편의 기준선을 다시 만들면, 튜터 사이트(논문 글쓰기 진단)의 기준선과 같은 결과가 나오는가?

## 조건
| | 내 도구 | 튜터 기준선(`baselines_acs2021`, 읽기만 함) |
|---|---|---|
| 추출 | pdf-extract-0.4.7 | pdf-extract-0.4.7+gnu.2 |
| 집계 | hedge-baseline-0.4.4 | hedge-baseline-0.4.4+gnu.2 |
| spaCy / 모델 | 3.8.11 / en_core_web_sm 3.8.0 | 같음 |
| pdftotext | 1차 Xpdf 4.00, 2차 **Poppler 26.09.0** | Poppler 26.10.0 |
| 논문 | 같은 80편(학술지마다 20편) | 같음 |
| 품질 점검 | 인용 회수 95%↑, 끝이 열린 문장 5%↓, 여백 누출 0 | 같은 기준 + 서론·결과논의 존재, 본문 1,000단어↑ |

실행: `run_mine.py`(내 도구의 추출·집계 코드를 그대로 부르고, Xpdf 비교를 위해 첫머리의 pdftotext 종류 검사만 건너뜀). 비교: `compare.py`.

## 결과

### 품질 점검을 통과해 기준선에 들어간 논문
| 분야 | 내 도구 + Xpdf | 내 도구 + Poppler | 튜터 |
|---|---|---|---|
| CM | 17 | 18 | 18 |
| IC | 15 | 15 | 17 |
| JOC | 1 | **1** | 15 |
| JPC C | 16 | 18 | 17 |
| 합계 | 49 | 52 | 67 |

- **Poppler로 바꾸자 CM·JPC C는 튜터와 거의 같아졌다**(Xpdf의 참고문헌 수 오류가 사라짐). → 앞으로는 Poppler를 쓴다.
- **JOC는 Poppler로도 1편만 통과했다.** 원인은 PDF 변환기가 아니라 **내 도구의 본문 추출**이다. JOC 논문은 실험 절(9 pt)이 길어서 본문 글자 크기를 잘못 고르고, 그 결과 **서론과 결과·논의 본문 대부분이 빠진다**(예: acs.joc.0c00186 — 내 도구 서론 0단어·결과논의 241단어, 튜터 서론 366단어·결과논의 1,249단어). 본문 인용이 빠지니 인용 회수율이 10~45%로 떨어져 탈락했다.
- 튜터 판 `pdf-extract-0.4.7+gnu.2`에는 바로 이 문제를 고친 규칙이 들어 있다("첫 쪽에서 가장 많은 본문 크기 텍스트를 보조 근거로 사용", `docs/baseline-correction.md`). IC 두 편(ic0c02748, ic0c03389)의 탈락도 같은 계열(본문 크기 판정)로 보인다.
- 반대로 JPC C jp1c08997은 튜터 쪽에서 "결과·논의 미인식"으로 빠졌고 내 도구에서는 통과했다(튜터 쪽에 추가된 점검 항목 차이).

### 둘 다 통과한 논문(Poppler, 51편)의 숫자
| 지표 | 비교 쌍 | 완전히 같음 |
|---|---|---|
| 절별 단어 수 | 193 | 192 |
| 헷지 /1,000단어 | 155 | 154 |
| 강조 /1,000단어 | 155 | 154 |
| 보고동사 /1,000단어 | 193 | 192 |
| 동사 /1,000단어 | 193 | **91** (차이 중간값 0.50) |

- 추출이 같은 논문에서는 **헷지·강조·보고동사가 사실상 완전히 같다.** 집계 규칙은 두 판이 같다.
- **동사 수만 체계적으로 다르다.** 튜터 판은 조동사 등 비어휘 동사를 빼고 센다(`prose_filters.is_lexical_verb`, +gnu 수정). 이 차이는 의도된 수정이다.

## 결론
1. 집계 규칙(헷지·강조·보고동사)은 **재현된다.**
2. 차이는 모두 튜터 판의 기록된 수정 세 가지로 설명된다: ① 본문 글자 크기 판정 개선(JOC·일부 IC), ② 비어휘 동사 제외(동사 수), ③ 품질 점검 항목 추가(서론·결과논의 존재, 1,000단어).
3. Xpdf는 쓰지 않는다(참고문헌 수 오류). **Poppler**로 고정한다.

## 정할 것(교수님)
- 앞으로 기준선(계산 16편, 실험 보강 20편 포함)을 만들 때 **내 도구에 위 세 가지 수정을 반영한 새 판(예: 0.4.8)**을 쓸지, 아니면 비교를 위해 0.4.7 그대로 둘지.
  - 반영하지 않으면 JOC처럼 실험 절이 긴 논문이 계속 빠지고, 사이트 기준선과 숫자가 맞지 않는다.
  - 반영하면 튜터 사이트에 그대로 얹을 수 있는 기준선이 된다. 수정 내용은 튜터 저장소 문서에 기록되어 있으므로, 반영 시 출처(박용규 튜터의 +gnu 수정)를 변경 기록에 밝힌다.

교수님 결정으로 위 세 가지 수정을 내 도구에 반영해 **0.4.8**(pdf-extract-0.4.8 / hedge-baseline-0.4.5, `prose_filters.py` 추가, run_stage1 품질 점검 확장)을 만들고, Poppler 26.09.0으로 80편을 다시 돌렸다. 이전 판은 `화학과 AI/스킬백업/section-verb-hedge-baseline_0.4.7_2026-11-09`에 보존. 전체 표: `비교_048_poppler.md`.

|---|---|
| 품질 점검 | **둘 다 통과 67, 둘 다 탈락 13, 한쪽만 통과 0** (CM 18, IC 17, JOC 15, JPC C 17 — 튜터와 같음) |
