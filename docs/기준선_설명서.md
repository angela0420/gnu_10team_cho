# 기준선 설명서 — ACS 2020–2021 CC BY 80편 (acs_80)

## 무엇인가
화학 연구논문 절별 헷지·강조·보고동사·동사의 1,000단어당 빈도 기준선. 새 원고를 진단할 때 "이 분야 논문들은 보통 이 범위"라는 참고로 쓴다. 점수나 정답이 아니다.

## 자료
| 항목 | 내용 |
|---|---|
| 학술지 | Chemistry of Materials(CM), Inorganic Chemistry(IC), J. Org. Chem.(JOC), J. Phys. Chem. C(JPC_C) |
| 기간 | 2020–2021 |
| 라이선스 | Crossref에 CC BY(ACS AuthorChoice CC-BY 포함)로 등록된 논문만. CC BY-NC·ND는 뺌 |
| 논문 종류 | 연구논문(Article)만. 리뷰·Note·단신·정정, 제목으로 본 계산 위주 논문은 뺌 |
| 뽑기 | DOI 순으로 늘어놓고 시드 20261101 난수로 섞어 학술지마다 본편 25편(기준 20 + 시험 5)과 예비를 뽑음 |
| 기준 논문 | 학술지마다 20편, 모두 80편(`paper_list.csv`) |
| 시험 논문 | 학술지마다 5편을 PDF를 받기 전에 따로 정해 두었고, 기준선을 만드는 데 쓰지 않았다(목록은 이 저장소에 넣지 않음) |

## 계산
| 항목 | 내용 |
|---|---|
| 코드 | section-verb-hedge-baseline 0.4.8 (pdf-extract-0.4.8 / hedge-baseline-0.4.5) |
| 환경 | Python 3.12, spaCy 3.8.11, en_core_web_sm 3.8.0, pdfplumber 0.11.10, poppler pdftotext |
| 품질 점검 | 인용 회수 95%↑, 끝이 열린 문장 5%↓, 여백 누출 0, 서론·결과논의 인식, 본문 1,000단어↑ |
| 통과 | CM 18, IC 17, JOC 15, JPC_C 17 (모두 67편). 탈락 13편과 이유는 `paper_list.csv`·`extract_gate.json` |
| 헷지·강조 목록 | Hyland (2005) 부록. 화학에서 문자 그대로 쓰이는 표현(can, about, show·find 등)은 합계에서 빼고 확인 후보로 따로 셈 |
| 값 | 절마다 논문별 1,000단어당 값을 구한 뒤 중간값과 최솟값–최댓값 |

## 읽는 법(예: 헷지, 1,000단어당)
| 분야 | 절 | 논문 | 중간값 | 최솟값–최댓값 | 가운데 50%(사분위) |
|---|---|---|---|---|---|
| CM | 서론 | 18 | 2.04 | 0–10.03 | 1.43–3.35 |
| CM | 결과·논의 | 12 | 5.49 | 1.61–9.09 | 3.91–6.98 |
| IC | 결과·논의 | 17 | 3.75 | 1.32–11.62 | 2.75–7.04 |
| JOC | 결과·논의 | 15 | 4.82 | 0–12.25 | 2.98–8.82 |
| JPC_C | 서론 | 17 | 2.74 | 0–11.54 | 0.98–4.95 |
| JPC_C | 결과·논의 | 16 | 5.03 | 1.80–9.96 | 3.90–6.74 |

- 결과·논의 절의 헷지가 서론보다 많다(해석을 조심스럽게 말하는 절).
- 최솟값–최댓값은 한 편만 특이해도 넓어진다. 원고를 볼 때는 **가운데 50% 범위**를 함께 보는 편이 낫다(사분위는 `baseline.csv`의 논문별 값으로 계산).

## 한계
- 분야당 15–18편: **예비 기준**이다. 한두 편 차이로 중간값이 움직인다.
- ACS 조판(2020–2021)에 맞춰 다듬은 추출 규칙이다. 다른 출판사·연도는 추출을 먼저 확인할 것.
- 헷지 판정은 규칙(낱말 목록과 품사)이다. 문맥상 헷지가 아닌 경우를 일부 걸러 내지만 완전하지 않다.
- 계산 위주 논문은 뺐다. 계산 논문 기준선은 따로 만들 예정(JPC_C 계산 16편).
- 저자–연도식 인용은 다루지 못한다.
