# 사용법

## 1. 준비
1. **Python 3.12** (3.14에서는 spaCy 3.8이 동작하지 않습니다. Windows는 `py -3.12`)
2. 패키지
   ```
   python -m pip install -r requirements.txt
   ```
   spaCy 3.8.11, en_core_web_sm 3.8.0, pdfplumber 0.11.10으로 고정되어 있습니다. 판이 다르면 숫자가 달라질 수 있습니다.
3. **poppler**의 `pdftotext`
   - Windows: <https://github.com/oschwartz10612/poppler-windows/releases> 에서 받아 풀고, `Library/bin`을 PATH 맨 앞에 둡니다(또는 `winget install oschwartz10612.Poppler`).
   - xpdf의 `pdftotext`가 먼저 잡히면 참고문헌 수가 틀려 품질 점검이 무너집니다. 도구가 감지하면 실행을 멈춥니다.

## 2. 기준선 만들기
```
python scripts/run_stage1.py <PDF 폴더> <출력 폴더> --max-papers 20
```
- 한 폴더에 한 분야(학술지)의 논문 PDF를 넣습니다.
- 출력
  - `1_extract/` 논문별 추출 본문과 절 구조 (**원문이 들어 있으니 공유하지 마세요**)
  - `extract_gate.json` 품질 점검 결과(통과·탈락과 이유)
  - `2_baseline/baseline.csv` 절별 지표의 중간값·최솟값·최댓값과 논문별 값
  - `2_baseline/per_paper.csv` 논문·절별 숫자
  - `2_baseline/evidence.csv` 셈의 근거 문장 (**원문 문장 — 공유하지 마세요**)

## 3. 품질 점검(이 기준을 모두 넘은 논문만 기준선에 들어감)
- 참고문헌 번호 가운데 본문 인용으로 복원된 비율 95% 이상
- 끝이 열린(문장부호로 끝나지 않은) 문장 5% 이하
- 여백(날짜·저작권·학술지 머리글) 누출 0
- 서론과 결과·논의 절을 알아봄
- 초록을 뺀 본문 1,000단어 이상

## 4. 새 원고 진단
새 원고(같은 분야)를 같은 방식으로 돌려 `per_paper.csv`의 절별 값을 이 저장소 `baselines/acs_80/<분야>/baseline.csv`의 중간값·범위와 비교합니다. 범위 밖이라고 틀린 것은 아닙니다. "이 분야 논문들은 보통 이렇다"는 참고로만 쓰세요.

## 5. 지표
| 지표 | 뜻 |
|---|---|
| `hedge_per1000` | 헷지(may, could, suggest that 등) 1,000단어당 |
| `booster_per1000` | 강조(demonstrate, clearly, indeed 등) 1,000단어당 |
| `reporting_per1000` | 선행연구 보고동사("X et al. reported") 1,000단어당 |
| `verbs_per1000` | 어휘 동사 1,000단어당 |

절 기호: INT 서론, MET 실험·방법(계산 포함), RES 결과, DIS 논의, RD 결과·논의, CON 결론. 실험·방법 절은 헷지·강조의 분모에서 뺍니다.
